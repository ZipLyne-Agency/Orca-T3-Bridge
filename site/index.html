00 / BEFORE YOU START

A Mac, Orca, and T3.

Install Orca and T3 Code on the same Mac. Open both apps and start an agent session in Orca. The bridge connects sessions that already exist.

  • macOS 13 or later, on Apple Silicon or Intel.
  • Orca and T3 Code installed and open.
  • An existing Orca agent session inside a project.
  • For phone access, T3 mobile paired with this Mac's T3 environment.
Compatibility matters.

This early release is verified with Orca 1.4.226 and T3 Code Nightly 0.0.46-nightly.20261014.3132. New app versions may need a bridge update. Check the current compatibility table.

01 / INSTALL

Download. Move. Open.

  1. Download Orca T3 Bridge.

    Get the Mac installer below. It contains a universal app for Apple Silicon and Intel.

    Download for Mac ↓

    ZIP, checksums, and release notes

  2. Drag the app into Applications.

    Open the downloaded disk image, then drag Orca T3 Bridge to the Applications folder.

  3. Open it from Applications.

    A link icon labeled Bridge appears in your menu bar. The setup window walks you through the connection.

The app is signed with ZipLyne's Developer ID and notarized by Apple. You don't need to install a runtime or run a command.

02 / CONNECT

Connect once. Keep your sessions.

With Orca and T3 open, click Connect Orca and T3. The app finds T3's local connection, registers the Orca provider, and imports your existing sessions.

When the menu bar panel says Connected, new agent sessions will be discovered automatically. If you create an empty project, start an agent session in it before expecting it to appear.

Both stable and nightly T3 are installed

Expand App locations and connection during setup and choose the T3 application you actually use. Both the Mac and phone must use that same T3 environment.

I already use the command-line bridge

The app keeps the configuration at ~/.config/orca-t3-bridge/config.json, along with the existing session identities and delivery receipts. Connecting moves the matching provider to the app's bundled runtime and removes a matching old sync LaunchAgent. Stop any manually started sync --watch process first.

If an existing provider belongs to another configuration, the app reports the conflict instead of replacing it.

03 / ON YOUR PHONE

The same agent, from T3.

Open the standard T3 Code mobile app and connect to the same T3 environment running on your Mac. In T3, open an imported Orca conversation.

  1. Read the recent history and the agent's progress.
  2. Write your reply in T3's normal composer.
  3. The bridge forwards it to the original Orca agent and brings its response back.

Imported history is grouped inside a refresh turn with You in Orca and Orca labels. New messages use T3's normal chat flow.

Your Mac is still doing the work.

Keep it awake and reachable, with Orca and T3 running. The bridge does not configure phone pairing, a tunnel, or port forwarding. Use T3's own remote-access setup.

05 / RESTARTS & UPDATES

Made to come back with you.

After connecting, the app enables launch at login. macOS may ask you to approve it in System Settings → General → Login Items. The menu bar panel shows when approval is needed.

Your sync preference and configuration survive app and computer restarts. If Orca or T3 is closed, the bridge waits and reconnects when they return. A paused bridge stays paused.

Sparkle checks for updates automatically. Update archives and the update feed are signed, and release apps are notarized. You can also choose Check for Updates from the menu bar.

Updates preserve your configuration and receipts. Existing T3 connections may finish using the previous bridge runtime until T3 reconnects; your Orca agents keep their sessions.

06 / THE BOUNDARIES

Keep the right work in the right app.

Use T3 for

  • Reading recent conversation history.
  • Following incremental agent output.
  • Sending text and resource links.
  • Answering supported native approvals and questions.

Use Orca for

  • Creating agents and changing models.
  • Managing tools and permissions.
  • Attaching images, audio, and embedded files.
  • Rich terminal prompts or unsupported forms.

The default history window is 1,000 items or 1 MiB. A “Showing recent Orca history” notice refers to what T3 displays. The original agent keeps its own context.

Stop and Pause are different.

An explicit Stop in a T3 conversation interrupts the Orca agent. Pausing discovery, quitting the bridge app, or disabling its provider does not stop that agent.

Discovery and refresh make no model calls. Your explicit reply can start paid work in the existing agent. The bridge does not set a provider-wide spending cap.

07 / GET UNSTUCK

A useful answer, before a bug report.

The panel says “Waiting for apps”

Open Orca and T3 on the Mac. Check that the T3 application and profile match your configuration. The bridge retries availability checks with a bounded delay; Sync Now requests another check immediately.

A new project hasn't appeared

Start an agent session in that project, then choose Sync Now. Empty projects and ordinary shells aren't imported as agent conversations. Workspaces removed from T3 stay removed. Add a workspace in T3 again to receive new sessions there; previously deleted conversations stay deleted. Check workspace filters if you've customized your configuration.

A reply failed, or delivery is uncertain

Inspect the original conversation in Orca before sending the message again. If Orca received it, use /orca-refresh to read the result. The bridge never automatically resends an uncertain prompt.

For a blocked delivery receipt, follow the receipt recovery instructions. Do not delete the state directory to clear the error.

The panel says “Needs attention”

Read the displayed error. A changed protocol, conflicting provider, or failed history import needs attention instead of an endless retry loop. Check for a bridge update, confirm compatible app versions, then choose Sync Now or reconnect in Settings.

It didn't open after restarting my Mac

Open the app from Applications and check Open at login. If macOS requires approval, use the panel's link to Login Items. The bridge starts after you sign in, not before login.

I need to report a problem

Include macOS, bridge, Orca and T3 versions, a sanitized error, and the steps that caused it. Remove credentials, project names, private paths and conversation text.

08 / PAUSE OR REMOVE

You're always in control.

Choose Pause to stop automatic discovery. Turn off Open at login if you don't want the app to reopen, then choose Quit Bridge.

To fully disconnect, disable the Orca provider in T3's provider settings before removing the Mac app. Imported history stays in T3, and the original Orca agents keep running.

Keep the bridge's private state if you plan to reconnect. It contains delivery receipts and history deduplication information. Resolve uncertain sends before removing state.
